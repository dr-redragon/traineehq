# TraineeHQ

Build a professional, modern medical training resource platform called "HST Training Hub"  for Higher Surgical and Specialty Trainees across multiple medical and surgical programmes  in the UK NHS system. --- ## DESIGN AESTHETIC Clean, authoritative, and trustworthy — think refined clinical professionalism with warmth.  Use a navy/slate primary palette with teal accent colours. Typography: a strong serif display  font (e.g. Playfair Display or Fraunces) paired with a clean sans-serif body (e.g. DM Sans).  Subtle animations on hover/load. Card-based layout with generous whitespace.  Dark sidebar navigation. Logo area should say "HST Training Hub" with a subtle caduceus or  stethoscope icon. --- ## AUTHENTICATION & SECURITY (GDPR COMPLIANT) - Secure login page with email + password fields - "Forgot password" flow with email reset link - On first login: display a GDPR consent banner/modal stating:     - What data is stored (name, email, specialty, login timestamps)     - Data is not shared with third parties     - User can request deletion of their account/data     - Cookies policy (essential only, no tracking cookies) - User profile page where users can:     - Update their name, email, specialty     - Download their stored data (GDPR subject access)     - Delete their account - All passwords must be hashed. Sessions use JWT tokens with expiry. - Role-based access: Admin and Trainee roles. Admins can add/edit/delete content.    Trainees can view only. - Login activity is logged (timestamp, IP address stored securely, not shared). --- ## HOMEPAGE (POST-LOGIN DASHBOARD) After login, show a dashboard with: - Welcome banner: "Welcome back, [First Name]" - Quick-access cards for each specialty the user is enrolled in - "Recently Added Resources" feed (latest 5 uploads across all specialties) - Upcoming events / announcements banner (editable by Admin) - Navigation sidebar with links to all specialty sections, Key Contacts, My Profile,    and Admin Panel (admin only) --- ## SPECIALTY SECTIONS Create the following specialties as separate sections, each accessible from the sidebar.  The list should be expandable by admins. Default specialties to include: 1. ENT (Otolaryngology – Head & Neck Surgery) 2. General Surgery 3. Trauma & Orthopaedics 4. Urology 5. Ophthalmology 6. Neurosurgery 7. Cardiothoracic Surgery 8. Vascular Surgery 9. Plastic Surgery 10. Oral & Maxillofacial Surgery 11. Obstetrics & Gynaecology 12. Paediatric Surgery 13. Anaesthetics & ICM 14. Radiology 15. Psychiatry 16. Internal Medicine / IMT Each specialty section must include: ### A) SUBSECTIONS (collapsible / tabbed) Each specialty can have multiple subsections that admins can create, rename, and reorder.  Default subsection examples:   - Curriculum Overview   - Exam Preparation (e.g. FRCS, MRCS, FRCR etc.)   - Core Clinical Skills   - Research & Audit   - Operative / Procedural Skills   - Teaching & Leadership   - Simulation & Courses   - Useful Guidelines & Protocols ### B) RESOURCE TYPES (within each subsection) Each subsection can contain multiple resource items of the following types:   - 📄 PDF — upload and display inline or downloadable   - 📝 Document — Rich text / formatted text document (editable inline by admin)   - 🎥 Video — Embed YouTube/Vimeo link or upload MP4 file   - 🔗 External Link — URL with title, description, and optional thumbnail   - 📊 Presentation — upload PowerPoint/PDF slides, display as slideshow   - 📋 Checklist — interactive checklist that trainees can mark off   - 🗂️ Folder — nested group of any of the above resource types Each resource card should show:   - Title   - Description (optional)   - Resource type icon/badge   - Date added   - Added by (admin name)   - Download / Open / Watch button Admins can add, edit, reorder, and delete any resource. --- ## KEY CONTACTS SECTION (per specialty) Each specialty must have a dedicated "Key Contacts" tab/page with a structured  contacts directory. Contact categories to include:   - 🏛️ Deanery / HEE Regional Contact   - 🎓 Training Programme Director (TPD)   - 👩‍⚕️ Associate Dean   - 🧑‍🏫 Educational Supervisors (list, with hospital trust)   - 🗳️ Trainee Representative (ST/ST Reg Rep)   - 📋 Royal College Contact / Specialty Advisory Committee (SAC)   - 🏥 Hospital / Trust Training Leads (list per trust)   - 📞 Rota Coordinator / Admin contact Each contact card should display:   - Full name   - Role/title   - Organisation / Trust   - Email address (obfuscated from scraping — display as "name [at] nhs.net")   - Optional: Phone number, profile photo   - Optional: Link to personal/departmental page Admins can add, edit, and archive contacts. Archived contacts are hidden from  trainees but retained for record. --- ## ADMIN PANEL Accessible only to admin-role users. Includes:   - User management: invite users, assign specialty, change roles, deactivate accounts   - Content management: add/edit/delete any resource in any specialty/subsection   - Contacts management: add/edit contacts in any specialty   - Announcements editor: create/edit homepage banners   - Audit log: view user activity (logins, resource views, downloads)   - GDPR tools:        - View/export user data by request       - Delete user accounts and associated data on request       - Cookie consent records --- ## ADDITIONAL FEATURES - 🔍 Global search bar: search across all specialties, resources, contacts by keyword - 📌 Bookmark / Save resource feature for trainees (saved to their profile) - 📣 Notification system: admins can send in-platform notifications to all users or       specific specialty groups - 📱 Fully responsive — works on mobile, tablet, and desktop - ♿ Accessibility: WCAG 2.1 AA compliant (proper contrast, alt text, keyboard nav) - 🌙 Light/dark mode toggle - 🇬🇧 UK spelling and NHS-appropriate language throughout --- ## TECH STACK PREFERENCES - Frontend: React with Tailwind CSS - Backend: Supabase (auth, database, file storage) - File storage: Supabase Storage for PDFs, videos, documents - Auth: Supabase Auth with RLS (Row Level Security) for GDPR compliance - Deployment: Vercel or Netlify --- ## TONE & VOICE Professional but approachable. This is for busy surgical and medical trainees —  content should be easy to find, navigation intuitive, and the platform should feel  like a trusted colleague's well-organised folder system, not a corporate intranet.
